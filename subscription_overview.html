How Premium Subscription works today

One monthly plan that gives free delivery. The app asks the backend whether the user is subscribed, shows either a status card or a plan card, and takes payment through Telebirr (in-app SDK or USSD push). The app never applies the free delivery itself; that happens on the backend.

Where state comes from

  1. _loadSubscriptionDetail() runs in initState. It calls getSubscriptionDetail(user_id, server_token). On success == true it sets _isActive, _subscriptionExpiry, _subscriptionDurationDays, and starts the entrance animation.

  2. _fallbackToLegacyData() runs if the call fails or returns success != true. It reads the cached userData.user.subscritption_data (note the existing typo in the field name), takes date_of_subscription + 30 days as expiry, and treats the user as active if is_user_subscribed is true and that date hasn’t passed.

  3. Days left = _subscriptionExpiry − now in whole days, clamped to 0–9999. Progress bar = daysLeft / planDay, clamped to 0–1.

The plan list is a getter, _subscriptionPlans, which returns a single map (“Monthly Premium”, ETB, purple gradient, three benefits). Every buy button now uses _subscriptionPlans[0]; older code indexed [1] for a second plan that no longer exists.

End-to-end flow

inapp_subscription_payment.dart

Telebirr InApp

  1. Create order. initState strips non-alphanumerics from traceNo (falls back to ZM<epoch ms>) and posts to create_order with a 15 s timeout.

  2. Pick platform. If createOrderResult.result is “success”, Android calls placeOrder(), iOS calls placeOrderIOS(), both with appId, shortCode and receiveCode.

  3. Native SDK. The Telebirr app opens. It returns a map with code; a PlatformException is read from e.details["code"].

  4. Confirm (Android only). On code == 0 it posts to in_app_call_back_for_subscription. Only if that returns success does it pop true; otherwise false. A non-zero SDK code is shown as −99 “Payment is not confirmed”.

  5. Message and pop. A toast is shown via _handlePaymentResponse, then the screen pops after 2 s.

ussd_subscription_payment.dart

Telebirr USSD

  1. Sheet pushes SubscriptionPaymentUssd with url = http://196.189.44.60:8069/telebirr/ussd/send_sms.

  2. initTelebirr() posts {traceNo, amount: 1, phone: "251"+phone, payerId: "22", appId: "4321", apiKey, zmall: true} with a 10 s timeout.

  3. If result.success, it shows “<message>. Waiting for payment to be completed” and an hourglass spinner. The user approves on the USSD prompt on their phone.

  4. That’s where it stops. _verifyPayment() is commented out, the screen never pops a value, and the caller has no .then(). The user has to go back, and the status only updates when they reopen the screen.

Gaps & risks

USSD payments never activate in-app bug

No .then() on the USSD push and verification is commented out, so the sheet stays open and polling never starts. Pop a value after a verify loop, or call _pollUntilActive() on return.

subscription.dart:1966 · ussd_subscription_payment.dart:46

iOS skips the confirm callback bug

placeOrderIOS pops code == 0 without calling in_app_call_back_for_subscription. If the backend relies on that callback, iOS users pay and then hit the 60 s timeout.

inapp_subscription_payment.dart:33

Credentials and raw-IP HTTP in the client security

USSD apiKey, appId and payerId ship in the app and go over plain HTTP to an IP address. Move the USSD call behind the ZMall backend.

ussd_subscription_payment.dart:121

Possible crash on SDK errors robustness

e.details["code"] is passed to an int parameter. If details is null or the code is a string, the catch block throws.

inapp_subscription_payment.dart:66, 121

Two sources of truth consistency

The plan view title still reads the cached legacy subscritption_data, while everything else uses the new endpoint. A user can see “Renew” based on stale cache.

subscription.dart:895

Payment gateway URLs hard-coded config

pgw.shekla.app and the USSD IP don’t follow ZMetaData.baseUrl, so they can’t be switched per environment.

inapp_subscription_payment.dart:251, 285
